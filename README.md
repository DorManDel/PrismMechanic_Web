# PrismMechanic_Web

Isolated Prism FX experiment site — **v5 Dual Preview**. This is separate from the live portfolio.

Live: https://dormandel.github.io/PrismMechanic_Web/

- Two synchronized examples: the Prism character and the profile picture from the public `DorManDel/Dor-s-Profile-Site` repository.
- Sensor auto-start when browser policy allows, with permission button fallback.
- Tilt geometry, camera framing, moving rainbow/highlight masks, response tuning, per-device Main Profile.
- Simple/Reduced Motion disables the effects and shows original photos.
- Portable JSON export for a later MyPortfolio developer settings panel.
- Read [MECHANICS.md](MECHANICS.md) for the mechanism diagram and architecture overview.

**Important:** personal uploads stay in the current browser tab. Stored settings use localStorage. Keep changes in this experimental repository until approved.
